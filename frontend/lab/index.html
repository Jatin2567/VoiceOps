THE FIELD GUIDE

Know what
you measured.

Architecture, precisely.

All three modes use recorded-turn Groq Whisper transcription and the same Groq reasoning model, prompt and tools. Buffered holds the complete response; streaming sends sentence-level speech as it becomes available. Guarded adds deterministic checks to sandbox actions.

This compares orchestration and delivery. It does not compare native speech-to-speech, continuous transcription, or full-duplex interruption handling.

Read the clock correctly.

Server first audio measures pipeline start to the first PCM frame. Browser first playback measures the client trial-ready signal to the first scheduled AudioContext sample. A streaming buffer adds a small playback lead. Neither measures acoustic output at your speaker.

STT, first LLM text token, TTS first audio and tool checks have separate observed timestamps. These stages can overlap; do not add them as if they form a single serial total. Missing measurements stay blank.

Make a fair comparison.

Input hashes verify identical WAV bytes across trials. Prompts, provider model names, task settings and results are exported. Each run starts fresh context. Run order rotates each repetition; provider caching, network traffic and free-host warm-up are uncontrolled.

Median and nearest-rank p95 use completed samples with measured playback. Counts and failed trials are shown. Three trials support exploration, not statistical performance claims. Repeat and export across sessions for stronger evidence.

Correctness and policy.

An optional expected phrase checks only that substring. Response quality needs human review. In action tasks the model calls a sandbox tool; guarded mode checks the action allowlist and amount limit. Model compliance can make all modes return the same result. A faster response is useful only if it meets the task.

Tool simulations have no external effects. Timing the policy measures local evaluation, not the model’s full tool round trip. Groq and Edge-TTS are live external services.

Failures are evidence.

Each run has a 60-second pipeline deadline. Two experiments can run at once; each contains up to nine trials. Disconnecting stops active work. Audio is held in memory and discarded after the experiment.

Free Render hosting can sleep. If the channel fails, reload and retry. Microphone permissions require HTTPS; use Chrome or Edge if the in-app browser does not grant access. The call studio retains the earlier hands-free booking demonstration.

Reproduce and inspect.

Export JSON for configuration, input SHA-256, per-run events, provider models, responses and playback measurements. CSV gives one row per trial. Timeline dots are observed server events; the displayed line length is relative to that run.

Tests verify buffering, packet delivery, stage order, tool policy and experiment validation. Live results are observations from the current run, never illustrative numbers.
